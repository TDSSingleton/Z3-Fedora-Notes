!! THIS IMAGE AND ITS MODULE TREE ARE A MATCHED PAIR. !!
Enabling FTRACE/KPROBES changed the size of struct module, so modules built
for stage 5 will NOT load against this kernel and vice versa -- they fail with
  .gnu.linkonce.this_module section size must match the kernel's built
  struct module size at run time
The kernel release is identical (7.2.15-q2q) so NOTHING warns. Mixing them
cost two full cycles today: it presents as display + touch + PCIe all dead at
once. If you flash stage 5 again, restore its module tree too
(/lib/modules/7.2.15-q2q.old on the device is the stage-5 one).
